# Simulator

This is the simulator component. It implements a simple [discrete-event
simulation](https://en.wikipedia.org/wiki/Discrete-event_simulation), where a
`simulator` coordinates the events scheduled by entities such as a `firebug`
(which sets things on fire), the `fire station` (which coordinates robots), the
`firefighting robots`, and the `grid` (which computes the progress of ongoing
fires).
